# LED Controller
The application is made as an exercise to understand the basics of TI's F28P65X device usage. The two LEDs of the launchpad are controlled via a command sent via SCI protocol. 

The syntax of the command is the following: "led 0/1 on/off/blink".

## Code analysis
### Console Management
The main loop starts waiting for the next character to be sent via SCI, which is then copied into a ring buffer of size 16.

- If the user sends a backspace character, then the buffer head is moved backward by one slot, which allows the user to delete characters previously sent.
- If the user sends the carriage return character, then a command buffer is allocated with the same size of the ring buffer. Then the last 16 characters from the ring buffer are copied into this new buffer. This separation of buffers allows to divide the problem into two easier ones: reading the characters one by one from the SCI interface, which requires a ring buffer that is more difficult to manage, and parsing the command, which can be handled more easily by using a simple buffer. 

All the functions related to console management start with CONSOLE_* prefix:

```
char CONSOLE_getCharacterAt(int8_t position);
void CONSOLE_writeCharacter(char character);
void CONSOLE_eraseLastCharacter();
void CONSOLE_copyCommand(char* cmdBuffer);
void CONSOLE_clearBuffer();
```
### LED Management
The following function controls the state of each LED:
```
void LED_setState(uint16_t ledIdx, LEDState state)
```
LEDState can be:
- ON/OFF: the LED is turned on/off
- BLINK: the LED is turned on/off periodically every second.

The following ISR
```
__interrupt void INT_LED_BLINK_TIMER_ISR(void)
```
manages the blinking of the LEDs. It is called on the interrupt generated by CPUTIMER0. The timer period is 200000000 cycles, which, with a system clock of 200MHz, corresponds to 1 second.

### App Management
The app is responsible to parse the command from a given command buffer and then executing some action. The function for doing so is the following:
```
void APP_parseCommand(char* commandBuffer)
```
After parsing the command, it calls the LED_setState function with the parameters (ledIdx, ledState) selected by the user.
